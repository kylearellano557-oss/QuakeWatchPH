🌏 QuakeWatch PH

QuakeWatch PH is a web-based earthquake monitoring application designed to provide users with information about recent earthquakes in the Philippines and around the world.

The application uses interactive maps and earthquake data to help users monitor seismic activity in an easy-to-understand interface.

✨ Features

- 🌍 World Earthquake Map — View recent earthquake activity around the world.
- 🇵🇭 Philippine Earthquake Map — Monitor earthquakes occurring within and around the Philippines.
- 📊 Earthquake Dashboard — View summarized information about recent earthquake activity.
- 🔎 Earthquake Information — View details such as magnitude, location, depth, date, and time.
- 🗺️ Interactive Maps — Explore earthquake locations using an interactive map.
- 📈 Earthquake Data Visualization — Present earthquake information in a clear and accessible way.
- 🌊 Tsunami Information — Display tsunami-related information provided by the earthquake data source.

🛠️ Technologies Used

- HTML5 — Web page structure
- CSS3 — Styling and responsive interface
- JavaScript — Application logic and data processing
- Leaflet.js — Interactive maps
- Chart.js — Data visualization
- SweetAlert2 — Alerts and dialogs
- USGS and SEISMIC PORTAL Earthquake API— Earthquake data

🌐 Data Source

QuakeWatch PH uses earthquake information provided by the U.S. Geological Survey (USGS) and SEISMIC PORTAL earthquake data service.

Earthquake information may include:

- Magnitude
- Location
- Depth
- Date and time
- Geographic coordinates
- Tsunami-related flag
- Other available earthquake information

💻 Running the Project Locally

Because QuakeWatch PH is a client-side web application, you can run it using a local web server.

For example, using VS Code with Live Server:

1. Clone the repository.
2. Open the project folder.
3. Start the local development server.
4. Open the provided local URL in your browser.

You can also use another local HTTP server of your choice.

📌 Purpose

QuakeWatch PH was developed as a web-based project for exploring earthquake data and presenting seismic activity through interactive maps and a simple dashboard interface.

The project is intended for informational and educational purposes. For official earthquake and tsunami warnings, users should refer to the appropriate government and scientific agencies.
